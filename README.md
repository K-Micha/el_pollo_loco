# El Pollo Loco – Webgame Projekt

Dies ist ein browserbasiertes 2D‑Jump‑and‑Run‑Spiel, das im Rahmen des Web‑Developer‑Lehrgangs entwickelt wurde.  
Das Projekt umfasst eine vollständige Landingpage, ein spielbares Game, Animationen, Sounds, Gegnerlogik sowie rechtliche Seiten (Impressum & Datenschutz).

---

## 🎮 Spielbeschreibung

In *El Pollo Loco* steuerst du einen animierten Charakter durch eine Wüstenwelt, sammelst Items, weichst Gegnern aus und besiegst den Endboss.  
Das Spiel läuft vollständig im Browser und wurde in JavaScript umgesetzt.

---

## 🏁 Features der Landingpage

- Ansprechende Landingpage mit thematischem Hintergrund  
- Start‑Button zum Spiel  
- Dialog‑Fenster mit Spielanleitung (öffnen/schließen per Klick)  
- Tastenbelegung einsehbar  
- Angepasste Schriftart  
- Optional: Story‑Erklärung  
- Optional: Fullscreen‑Modus  
- Impressum & Datenschutzerklärung verlinkt  

---

## 🎮 Features des Spiels

### Gameplay
- Start über Button  
- Spieler wird nicht direkt von Gegnern überrannt  
- Gleichmäßiger Hintergrund ohne Lücken  
- Hintergrundmusik + Soundeffekte  
- Mute‑Button (Status wird im LocalStorage gespeichert)  
- Endscreen bei Sieg oder Niederlage  
- Restart‑Button  
- Zurück zur Landingpage  

---

## 🧍‍♂️ Charakter

- Durchgehend animiert  
- Flüssige Sprunganimation  
- Idle‑Animation  
- Sleep‑Animation nach 15 Sekunden  
- Einsammeln von Coins & Flaschen → Statusbar aktualisiert  
- Flaschen werfen → Gegner sterben / Boss nimmt Schaden  
- Sounds für Aktionen (z. B. Schnarchen)  
- Schaden reduziert Lebensanzeige → Game Over bei 0  

---

## 🐔 Gegner

- Mindestens 2 Gegnertypen + Endboss  
- Unterschiedliche Größe, Geschwindigkeit und Verhalten  
- Flüssige Animationen (Idle, Walk, Hurt, Dead)  
- Gegner sterben nur bei korrektem Treffer (Offsets passen)  
- Endboss ist stärker und hat eigene Sounds  

---
